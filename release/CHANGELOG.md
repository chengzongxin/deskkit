# 更新日志

## 0.9.8-win

- 窗口变宽时，快捷项按设计比例放大，图标放大到一倍半，不再挤成一小格。
- 分组里面可以拖动快捷项排序。

## 0.9.7-win

- 唤出搜索和快捷启动时，先按最终尺寸画好再显示，不再先小后大闪一下。
- 快捷项每一行从同一左边距排开。图标加大，名字缩小并贴近图标。
- 背景图先按窗口大小缩小再铺上，细线不再裂开。图标按更大尺寸取样。
- 文字改用更清楚的光栅，仍是微软雅黑常规体。

## 0.9.6-win

- 背景图按原比例铺开，不再被拉变形。设了背景后，分组栏和标题栏不再另铺一层底色。
- 搜索框变矮，当前结果行改成淡色高亮。搜索和快捷启动里的分隔线去掉了。
- 快捷项和分组的右键菜单按行排开。「移动到分组」悬停后在右侧展开。
- 去掉底部「新建分组」按钮，在左侧空白处右键即可新建。全部分组不再给分组和快捷项铺深色底。

## 0.9.5-win

- 第一次在另一台电脑上启动时，扫描开始菜单不再因为目录快捷方式报错退出。

## 0.9.4-win

- 双击 `deskkit.exe` 会打开窗口。上一版在别的电脑上可能只停在托盘里，看起来像没有运行。
- 显卡初始化失败时会弹出说明，不再直接退出。
- 开机自启仍留在托盘，不弹出窗口。

## 0.9.3-win

- Windows 程序改为 C++ / Dear ImGui。便携包里带上 `deskkit.exe`、拼音表和 `contracts`，解压后可以直接运行。
- 便携包把编译器的运行库打进 exe。其他 Windows 10 / 11 电脑不再因为缺少 `libwinpthread-1.dll` 而无法启动。

## 0.9.2-win

- 设置「常规」里的「放入」除了系统工具，还会把开始菜单或其他已安装应用放进「应用」分组。已经在库里的不会重复添加。

## 0.9.1-win

- 快捷启动第一次打开且还没有快捷项时，把这台电脑上找得到的系统工具和自带应用按分组放进去。已经有快捷项的库不会被改动。
- 设置「常规」里的「放入」可以再补一次。已经在库里的路径不会重复添加。

## 0.9.0-win

- Windows 先行。这一版接通契约、呼出热键和空的主浮层。
- 搜索、分组和内置工具在后续任务里接上。
- 快捷启动面板：快捷项右键可「打开所在文件夹」或「删除」。Windows 与 macOS 同一套文案和菜单。
- 快捷启动面板：点击快捷项或按回车打开后，窗口自动隐藏。Windows 与 macOS 一致。
- 快捷启动面板默认热键为两个键：Windows `Alt+D`，macOS `⌥+D`。
- 快捷启动面板：点击窗口以外的区域约 150ms 后自动隐藏。Windows 与 macOS 一致。
- 快捷启动面板：分组整行长按即可拖动排序，短按仍是选中。Windows 与 macOS 一致。
