# DeskKit 产品命名方案

> **正式名未定。** 界面、仓库和文档继续用 DeskKit。不要按本文改品牌位。

> 文档版本：v1.0 ｜ 撰写：许清楚（产品经理）｜ 团队：software-deskkit
> 上下文：`docs/01-PRD.md`（0 节 TL;DR / 1.2 价值主张 / 1.3 产品定义 / 2.3 差异化机会点）
> **边界声明**：本文只输出命名建议，**未修改任何现有交付物**（PRD、架构文档、`prototype/index.html`、QA 报告、测试脚本均未改动）。原型内 "DeskKit" 品牌位与 140 项验收基线（源码 md5 `1fc47e74727696c2fa21a9c7a104d293`）已冻结，是否落地改名由用户后续决定。
> **初筛声明**：第 1 节「重名初筛结论」来自 WebSearch 粗略检索（2026-11-12，3+3 组关键词、交叉比对官网/应用商店/商标库），**不是商标检索、更不是法律结论**。三档定义：`疑似占用` = 检索到同名或高度近似产品；`未见明显占用` = 本次检索未发现同名产品；`需专业商标检索` = 通用词/近形词风险，须由专业机构判定。定名前必须做正式商标检索。

## 0. 结论先行

### 0.1 TOP 1 推荐名

| 项 | 内容 |
|---|---|
| **中文名** | **一唤**（2 字，yī huàn） |
| **英文名** | **Hail**（4 字母 / 1 音节，/heɪl/） |
| **成对关系** | 义近成对：中文「一呼即来」，英文 hail = 招呼、一呼即至 |
| **Slogan** | **「唤一下，办完一件事」** |
| **一句话理由** | 「一唤」直接对应产品最核心的动作——按一个键呼出、办完一件事就走；Hail 短、好拼、无平台词根也不撞任何竞品词根，四项产品气质（快 / 轻 / 可信 / 开放）都能被「一呼即来、用完即走」一句话兜住。 |

### 0.2 三句补充结论

| # | 结论 |
|---|---|
| 1 | **最大风险是可注册性**：初筛发现 Hail 已被多行业使用（学校传播平台含 "Hail App"、香港打车 App、F-Droid 同名系统工具、美国第 9 类 HAIL 商标记录）。因此**可注册性是一票否决项**，不是纯加权项：定名流程必须「先过专业商标检索 → 再定英文副名」。 |
| 2 | **中文主名可独立保留**：若英文 Hail 检索不过，建议保留「一唤」作中文主名，英文降级为 `Hark`（4 字母，冷门）或 `Flick`（5 字母，近形风险见 1 节），或转纯中文方案；中文名不随之作废。 |
| 3 | **本次核实最重要的发现**：通用英文短词（Dash / Swift / Sora / Brisk / Whisk / Pronto / Pico）与中文「即X」词族（即刻达 / 即办 / 一席）在软件类目**几乎全部被占用**，且有两款撞在我们自己的品类上（Whisk = macOS 剪贴板管理器，Brisk = 跨平台桌面工具）。所以命名方向应偏向「**中文短主名 + 冷门/自造英文短副名**」，不要指望捡到一个干净的通用英文词。 |

### 0.3 命名约束对照（本方案如何满足）

| 约束 | 落实方式 |
|---|---|
| 气质：快 / 轻 / 可信 / 开放 | 全部候选避开「管家 / 助手 / 大师 / 神器 / 全能」；不用夸张词，用动作词（唤、叩、应、拂）表达「一个动作完成一件事」 |
| 双端中性 | 无 Win / Mac / Dock / Spot / Finder 词根；所有候选均可同时用于 Windows 与 macOS |
| 输入友好 | 中文 2–3 字、无生僻字（「叩 / 枢」已在表中标注书面度）；英文 4–8 字母、1–2 音节、无连字符与数字 |
| 中英兼顾 | 主推成对方案；纯中文 / 纯英文方案给出取舍说明 |
| 避开竞品影子 | 与 Rolan / uTools / Raycast / Alfred / Listary / Wox / Launchy / Quicksilver / Flow Launcher / PowerToys Run 逐一比对近形近音；`-ox / Quick- / Ray- / List- / Launch` 系全部排除 |
| 避免纯功能描述 | 排除「快捷启动器 / 效率工具箱 / 一键达」类描述词 |

## 2. 评估矩阵（TOP 5）

### 2.1 维度与权重理由

| 维度 | 权重 | 为什么是这个权重 |
|---|---|---|
| 易记性 | 15% | 口碑传播靠「听一次就记住」，与输入友好并列为日常高频项 |
| 中英发音 | 10% | 影响双端/双语一致，但可通过「主副名」策略补偿，故权重最低之一 |
| 输入友好 | 15% | **用户每天要在搜索框、触发词、插件市场、域名里打这个词**，短与好拼是硬需求 |
| 气质契合 | 15% | 必须同时覆盖快 / 轻 / 可信 / 开放，且不能落入过时夸大词 |
| 双端中性 | 10% | 是准入门槛（一票检查项），所有候选都满足，区分度低 |
| 差异化（避开竞品） | 15% | 与 10 个竞品近形近音会直接造成用户混淆与品牌依附 |
| **可注册性初筛** | **20%** | **最高权重**：名字要能用于官网、应用商店、商标与插件市场 ID；且本次核实发现通用词普遍被占用，是最大现实风险 |

### 2.3 加权结论

| # | 结论 |
|---|---|
| 1 | **一唤 / Hail 综合第一（4.30）**：除可注册性外 6 项几乎满分，尤其「气质契合」「差异化」「输入友好」无短板，是最贴产品核心动作的名字。 |

## 3. 落选说明（看起来不错，但被否掉）

| 名称 | 为什么看起来不错 | 否决原因（含核实依据） |
|---|---|---|
| **Dash** | 4 字母、1 音节，「快」的联想最准，几乎完美贴合 | **Kapeli Dash** 是 macOS 知名 API 文档 / 片段管理器，且官方集成 Alfred / Quicksilver / LaunchBar / Raycast —— 与我们**同生态同人群**，属强占用 + 竞品影子 |
| **Swift** | 快且优雅，国际认知高 | Apple Swift 编程语言强占用；气质偏开发者 / 偏重，与「通用办公人群」不符 |
| **Sora** | 4 字母、轻快好拼、国际化顺 | OpenAI Sora（视频生成模型 + App，2025-09 上线、5 天破百万下载）强占用；偏日系、偏娱乐，与「可信办公」气质冲突 |
| **Quick / Quickly / Quicker** | 最直白的「快」 | 与竞品 **Quicksilver** 同词根，违反「避开竞品影子」；且属纯功能描述词 |
| **一席** | 中文 2 字、雅、桌面「一席之地」意象 | 已有知名「一席」演讲平台 App（App Store / 微软商店 / 安卓全渠道）。教训：**中文名不能只看字面，必须查应用商店** |
| **Pico** | 轻 + 微生态感，贴合插件生态 | 字节 Pico VR、Raspberry Pi Pico 国内强占用；且「微」不等于「快」 |
| **Nox / Vox / Mox / Rox** | 短、有力、好拼 | 与竞品 **Wox** 近形近音，`-ox` 词族整体排除 |
| **DeskKit（现内部代号）** | 含义准确、团队已通用 | ① `Desk + Kit` 是纯功能描述，与 uTools「工具箱」意象撞车，缺记忆点；② 已是工程代号，正式名与代号同名会造成品牌/仓库混淆；③ 原型品牌位与 140 项 QA 基线已冻结，改名需走变更流程 → **保留作工程代号，不升为品牌名** |
| **一键达 / 快捷启动器 / 效率工具箱** | 用户一眼懂 | 纯功能描述词，无品牌性、无法注册为显著商标，违反命名约束 5 |

## 4. 可注册性初筛：关键发现汇总

| 发现 | 证据（WebSearch 核实 2026-11-12） | 对命名的直接影响 |
|---|---|---|
| 通用英文「快词」在软件类目几乎全被占用 | Dash（Kapeli）、Swift（Apple）、Sora（OpenAI）、Brisk（跨平台下载器）、Whisk（macOS 剪贴板管理器）、Pronto（效率 App / 团队沟通）、Jiffy（Jiffy.ai）、Velo（veloapp.io） | 不要指望捡到干净的通用英文词；优先中文短主名 + 冷门/自造英文副名 |
| 有两款撞在**我们自己的品类**上 | Whisk = 剪贴板管理器（对应 P0 剪贴板历史）；Brisk = 跨平台桌面 Utilities（同样是双端桌面工具） | 这类同名比跨行业同名更危险，必须一票否决 |
| 中文「即X / 一X」词族拥挤 | 即刻达（外贸获客）、深即达（A2A IM）、即刻职达（招聘）、即办（App Store 商务协作）、一键事达（政务）、一席（演讲平台 App） | 中文名也要做商店 + 商标双重检索；「即达 / 瞬办 / 一席」均降级 |
| Hail 存在多行业同名但**未见桌面启动器同名** | `get.hail.to`、香港打车 Hail、F-Droid「Hail」系统工具、Justia 第 9 类 HAIL 商标（已 Abandoned） | 支撑 A1 进入 TOP1，但必须标注「疑似占用 + 需专业检索」并准备降级方案 |

> 再强调：以上均为**公开网络粗略检索**，未查各国商标局正式数据库、未做近似判断、未覆盖未上架产品与在先申请，**不构成法律结论**。

## 5. 落地检查清单（定名后要做的事 · 只列清单，本次不执行）

| # | 检查项 | 要点 |
|---|---|---|
| 1 | 域名与社媒账号 | 主域名 + 常见后缀 + 拼音变体 + 防钓鱼近似域名；同步查微博 / 公众号 / GitHub / npm 同名占用 |
| 2 | 应用商店名称 | Microsoft Store 与 Mac App Store（或独立分发）的名称长度、副标题、关键词、分类、截图品牌位；两端名称必须一致 |
| 3 | 专业商标检索 | 第 9 类（软件）、第 42 类（技术服务）、第 35 类（广告/市场）；CN / US / EU 近似判断；**未通过即启用降级名** |
| 4 | 代码与生态 ID | GitHub 组织 / 仓库名、插件市场 ID、包名与命名空间、协议头与版权声明；明确 **DeskKit 是否仅保留为工程代号**，避免品牌名与代号混用 |
